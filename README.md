# password-manager
Allows you to save passwords and search for previous passwords

Features 
- Generates randomized passwords with letters, numbers, and symbols
- Saves website name, username, and password to a json file
- Allows searching for password by website name
- Provides a GUI for saving passwords

Technologies
- Python
- Libraries: Tkinter, JSON, Random, Pyperclip

What I Learned
- GUI Development
- Random generation of passwords
- Read, write, and structure JSON files
